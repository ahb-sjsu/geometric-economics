Instrument screens

Study: Choices about points for you and for a charity.
Principal investigator: Andrew H. Bond, San José State University.

These are pictures of every screen of the study's web page, in the pilot's mode. A headless browser took them on 2026-11-07, from the version of the page registered with the study's design. The page ran with test settings, so the contact details read "Round-trip test", "test@example.org", "test board" and "Protocol TEST", and the receipts address reads "https://example.org/receipts". The deployed page shows the real ones.

The consent screen (screen 3) shows the draft text registered with the design. The page will show the approved consent notice, attached separately, word for word, with a link to the stamped copy.

The main study's screens are the same, except that it has 140 choices instead of 160 and no closing questions (screen 13).

Three screens are not pictured. Their full text is:

After declining consent:

Thank you. You chose not to take part, and nothing has been recorded. Please return the study on Prolific.

If the page is opened before the study is set up:

This study is not open yet. Please return the study on Prolific. Nothing has been recorded.

If the participant comes back to the page after finishing:

You have finished. Thank you for taking part. If Prolific did not open, please use the button below. [Finish and return to Prolific]
